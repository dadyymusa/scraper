# The Polite Scraper

A polite, resilient web scraping pipeline built in Python to collect, clean, validate, and store book catalog data from a practice sandbox.

---

## Target Classification

* **Target Website:** [Books to Scrape](https://books.toscrape.com/)
* **Purpose:** Educational/Practice — Books to Scrape is an explicit practice sandbox created specifically for developer training and scraping exercises.
* **Scope:** The first 3 catalogue pages only (discovering up to 60 unique book detail pages).
* **Data Collected:** Book title, product page URL, price text, numeric price in GBP, availability, rating, description, source page URL, and fetch timestamp.
